| [Acceso y usuarios](acceso_y_usuarios/README.md) | Identidad, sesión Web, aprovisionamiento, roles y permisos compartidos. |
| [APIs externas](externas/README.md) | Autenticación con Auth0 y correo transaccional con Resend. |

Para utilizar los endpoints, consulta [uso general y autenticación](uso_general.md) y [respuestas y errores](respuestas_y_errores.md). La [organización de las APIs](alcance_y_pendientes.md) describe la función de cada grupo y la relación entre los servicios.
