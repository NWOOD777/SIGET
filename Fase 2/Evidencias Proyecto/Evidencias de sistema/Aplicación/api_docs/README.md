# Documentación de las APIs de SIGET

La documentación se organiza por servicios de negocio, acceso e integraciones externas. Cada ruta tiene un archivo específico; cuando admite varios métodos, se explican juntos en ese archivo.

| Área | Contenido |
|---|---|
| [API 1 — Gestión de Activos y Asignaciones](api_1_activos_asignaciones/README.md) | Inventario, solicitudes, decisiones, entregas, asignaciones y devoluciones. |
| [API 2 — Service Desk y Taller/Reparaciones](api_2_service_desk_taller/README.md) | Tickets, catálogos y políticas de atención implementadas. |
| [Acceso y usuarios](acceso_y_usuarios/README.md) | Identidad, sesión Web, aprovisionamiento, roles y permisos compartidos. |
| [Bitácora de auditoría](auditoria/README.md) | Registro histórico protegido de operaciones y eventos críticos. |
| [APIs externas](externas/README.md) | Autenticación con Auth0, correo transaccional con Resend y generación QR con QR Server. |

Para utilizar los endpoints, consultar [uso general y autenticación](uso_general.md) y [respuestas y errores](respuestas_y_errores.md). La [organización de las APIs](organizacion.md) describe la función de cada grupo y la relación entre los servicios.
