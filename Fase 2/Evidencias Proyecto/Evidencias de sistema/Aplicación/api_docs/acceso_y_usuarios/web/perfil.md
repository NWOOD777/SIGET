# Consultar Mi perfil

`GET /perfil/` está disponible para un Usuario solicitante activo. Muestra los nombres, apellidos, correo y RUT del usuario conectado. Los datos son de consulta; su corrección corresponde al Administrador del sistema. La página enlaza con la recuperación de acceso y no permite cambiar contraseñas locales.
