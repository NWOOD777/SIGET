# Consultar estados de tickets

Ruta: `/api/tickets/estados/`

| Método | Acceso | Respuesta correcta |
|---|---|---|
| `GET` | Cuenta SIGET activa. | `200`, lista del catálogo. |

Entrega `id_estado_ticket`, `nombre` y `descripcion` por registro.

No recibe cuerpo.
