# SIGET

## Sistema Integral de Gestión de Equipos y Soporte Tecnológico

SIGET es una solución informática orientada a centralizar la administración
de activos TI y gestionar los servicios de soporte técnico institucional
bajo un modelo de Service Desk (Mesa de Ayuda).

La plataforma integra la gestión, control, trazabilidad y préstamo de
equipamiento tecnológico con un sistema de soporte técnico que permite
gestionar incidentes, requerimientos, diagnósticos, reparaciones y órdenes
de trabajo.

## Tecnologías

- Python
- Django
- Django REST Framework
- PySide6
- PostgreSQL
- Docker
- Docker Compose
- HTML5
- CSS3
- JavaScript

## Metodología

El proyecto será desarrollado utilizando el marco de trabajo ágil Scrum.

## Componentes principales

### Plataforma Web
Portal de autoservicio destinado a los colaboradores de la organización.

### Aplicación de Escritorio
Consola destinada a técnicos de soporte y administradores de TI.

### Backend / APIs
Servicios RESTful encargados de centralizar la lógica de negocio y
permitir la comunicación entre los diferentes componentes de SIGET.

### Base de Datos
Base de datos relacional PostgreSQL encargada de almacenar la información
de activos, préstamos, usuarios, tickets, reparaciones, repuestos,
auditoría y demás componentes del sistema.
